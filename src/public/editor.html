Markdown 编辑器帮助

开始写作

  • 左侧编辑 Markdown，右侧实时预览并支持 Mermaid、KaTeX、代码高亮。
  • 工具栏可快速插入标题、列表、引用、代码、链接、图片、表格和 Mermaid。
  • 本地图片会上传到当前文档同目录的 assets 子目录。

视图与导出

  • 使用「编辑 / 双栏 / 预览」切换布局，拖拽中间分隔线调整宽度。
  • 支持导出 Markdown、HTML、Word、PDF 和 PNG 长图。

常用快捷键

  • Ctrl/Cmd+S 保存，Ctrl/Cmd+Z 撤销，Ctrl/Cmd+Y 重做。
  • Ctrl/Cmd+B/I/U 加粗、斜体、下划线。
  • Ctrl/Cmd+K 插入链接，Ctrl/Cmd+Shift+K 插入图片。
  • Ctrl/Cmd+F 查找，Ctrl/Cmd+H 打开替换。
